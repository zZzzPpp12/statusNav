# StatusNav

一个独立实现的 macOS 原生状态栏工具，把电池、网络和音量放进一个动态图标。

- 外环：电池电量，充电显示绿色、低电量显示橙色。
- 中心：Wi-Fi、有线网络或离线状态，充电时显示闪电。
- 底部：四个音量指示点，静音时熄灭。
- 点击图标：查看电池、网络、音频设备概览，展开更多读数；调整输出音量、静音、选择输出与输入设备、调整输入音量。
- 电池：电量与供电状态、预计时间、健康状况、容量估计、循环次数、电压、适配器功率和低电量模式。硬件未提供的读数不补造。
- 网络：当前接口与 IP、无线协商速率；展开查看频段、信道、无线标准、信号、噪声、安全性与低数据模式。
- 蓝牙：展示系统记录的已配对设备、连接状态和可读取的设备电量（包括部分耳机的左、右、盒）；不主动扫描、配对或连接设备。面板打开时约每 30 秒刷新，也可手动刷新。
- 功耗流：电池净流入/流出估计、适配器输入、系统整机、可用的内置屏背光与 USB/Type-C 通道读数；电池详情内显示可监测应用的 CPU 能耗估计、CPU 活动和进程内存。
- 状态栏外显：电池净功率和网络实际上下行速率可以分别启用或关闭，默认关闭；偏好设置和右键菜单均可切换。
- 声音：直接显示可选择的输出设备、当前设备、连接类型与采样率；麦克风展开后显示输入设备和输入音量，不采集音频。
- 右键图标：偏好设置与退出。支持百分比显示、状态颜色、图标大小以及 Dock 实时图标。
- 面板在 macOS 26+ 使用系统标准 Liquid Glass，更早系统使用原生毛玻璃；透明根容器、材质和内容分别布局，内容不叠加底色。窗口跟随内容高度，屏幕空间不足时可滚动。系统开启“辅助功能 → 显示 → 降低透明度”时，材质会遵循系统设置显示为实色。

## 运行与构建

运行需要 macOS 13+；构建需要 Swift 6 与 macOS 26 SDK（Xcode 26+）。当前在 Apple Silicon、macOS 26 SDK 环境开发；其他系统版本尚未实机验证。

```bash
swift run StatusNav
```

生成本机架构的 App（本地 ad-hoc 签名）：

```bash
bash scripts/build-app.sh
open dist/StatusNav.app
```

本地构建未经过 Developer ID 签名或 Apple 公证，适合本机运行，不作为正式分发包。

```bash
swift test
```

## 实现

SwiftUI 提供面板与设置；AppKit 管理菜单栏和 Dock；IOKit 读取电池；Network 与 CoreWLAN 读取连接状态；CoreAudio 读取与控制音频设备。电池和音频使用系统事件，15 秒低频轮询兜底。实际网络流量来自 64 位网卡计数，约每 2 秒更新；功耗约每 4 秒读取。面板关闭且对应外显关闭时停止快速采样；应用活动只在电池详情打开且该选项开启时采样。没有第三方依赖。

`Sources/StatusNavCore` 包含可测试的状态模型；`Sources/StatusNav` 包含系统适配、UI 和图标绘制。

## 当前边界

- 不申请定位权限。macOS 隐藏 Wi-Fi 名称时显示“Wi-Fi 已连接”；通过系统设置切换网络。
- 网络状态表示系统存在可用路径，不保证外部互联网或特定网站可访问。无线连接速率是链路协商值，不是互联网测速结果。
- HDMI、数字输出等设备可能不支持系统音量或静音；对应控件自动禁用。
- 硬件分项不是所有机型都能提供；内置屏功率仅指背光，USB 通道编号不映射物理接口，分项可能包含在系统整机读数中，不能重复相加。无法读取时显示不可用，不用 0 W 代替。
- SMC 与 IORegistry 读数为只读、尽力读取，传感器键没有跨机型稳定契约。电池和电源管理报告可能延迟，不能当作实验室实时测量。
- 软件数据只包含当前用户可读取的进程；CPU 能耗不含 GPU、屏幕、网络等整应用耗能，不可用时只展示 CPU 活动。蓝牙断连设备不展示历史电量。
- 暂无充电限制控制、全局快捷键和自动更新。
- 系统状态在本机读取，无遥测或统计上报；偏好设置保存在本机 UserDefaults。
