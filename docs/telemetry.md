# 蓝牙、功耗与状态栏读数

## 数据范围

蓝牙读取系统设备报告和可归属到同一蓝牙地址的 HID 电量缓存。报告失败与设备为空分别处理；已断连设备的历史电量不作为当前电量展示。耳机左、右与盒的电量分别标注，不拿单侧电量充当整体电量。读取不发起扫描、配对或设备连接。报告子进程有时限、输出大小限制和私有临时文件，面板关闭时停止定期读取。

网络速率由当前系统路径的接口 64 位收发字节计数差与实际单调时钟间隔计算。更换接口、计数回退、睡眠/长间隔后重新建立基线，不产生尖峰。显示的是该接口实际流量，并非互联网测速，也不是 Wi-Fi 协商速率。

功耗层只读固定 SMC 传感器和电源管理报告。电池净功率由电压与有符号电流估算，需匹配当前外接电源状态并验证报告时间；充入与放出分开显示。内置屏使用可用的背光传感器，未激活内屏与读不到功率不是同一个状态。USB/Type-C 只合计可读通道，既不将协商功率当作实际功耗，也不猜测通道对应的插孔或设备。系统整机可能包含分项，因此不强行做总和与剩余功耗拆分。

软件读取当前用户的可访问进程，按应用包归属汇总。CPU 时间转换为纳秒后取差值；能耗使用内核 CPU 能量计数取差，缺失时只按 CPU 活动排序。PID 复用、计数回退与长间隔不沿用旧基线。只读到部分进程能耗时标明覆盖数量。内存是这些进程物理足迹的合计；这些数值都不是整应用完整耗能，也不是活动监视器的“能耗影响”评分。

## 开关与采样

电池净功率和网络上下行外显独立保存于 UserDefaults，默认关闭。偏好设置和右键菜单都能即时切换，不更改其他图标偏好。不可用读数显示破折号；关闭后移除对应外显。

面板可见或功率外显开启时约每 4 秒读取功耗；面板可见或网络外显开启时约每 2 秒读取流量。应用活动还要求电池详情已展开且用户允许该项。面板关闭且外显关闭时停止快速采样。休眠唤醒清除基线与旧蓝牙报告；异步旧结果不覆盖新状态。

## 验证

纯模型测试覆盖零电量与缺失值、连接状态和地址去重、单侧耳机电量、计数重置、PID 复用、功率方向、SMC 数值编码，以及外显开关的独立性。原生自检使用实际读取的快照，在布局检查前暂停采样，防止硬件状态变化干扰几何断言；可通过 `--preview-details --preview-short` 验证长详情的滚动。

`--smoke-test --preview-readouts` 临时启用两项外显并验证原生状态栏文本，使用进程内参数域，不写入用户持久偏好。
