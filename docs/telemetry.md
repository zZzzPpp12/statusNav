# 蓝牙、功耗与状态栏读数

## 数据范围

蓝牙读取系统设备报告和可归属到同一蓝牙地址的 HID 电量缓存。报告失败与设备为空分别处理；已断连设备的历史电量不作为当前电量展示。耳机左、右与盒的电量分别标注，不拿单侧电量充当整体电量。读取不发起扫描、配对或设备连接。报告子进程有时限、输出大小限制和私有临时文件，面板关闭时停止定期读取。

网络速率由当前系统路径的接口 64 位收发字节计数差与实际单调时钟间隔计算。更换接口、计数回退、睡眠/长间隔后重新建立基线，不产生尖峰。显示的是该接口实际流量，并非互联网测速，也不是 Wi-Fi 协商速率。

功耗层只读固定 SMC 传感器和电源管理报告。电池净功率由电压与有符号电流估算，需匹配当前外接电源状态并验证报告时间；充入与放出分开显示。内置屏使用可用的背光传感器，未激活内屏与读不到功率不是同一个状态。USB/Type-C 只合计可读通道，既不将协商功率当作实际功耗，也不猜测通道对应的插孔或设备。系统整机可能包含分项，因此不强行做总和与剩余功耗拆分。

电池模块默认并排显示“充电器输入”“电池功率”和“系统消耗功率”三个紧凑读数，无需展开详情。充电器项使用实际输入读数，不采用适配器额定功率替代；电池项显示净功率的大小与充入/放出方向；无有效读数时显示“不可用”。电量进度填充在模块左侧的电池图标内部，不再单独占用横向进度条。

三个功率卡片可分别点击，进入固定在面板顶部的动态输入／输出详情页。三个模块共用 448 点的紧凑高度，屏幕空间不足时使用更小的统一视窗；不按模块内容分别计算高度。顶部保留返回按钮和三个切换卡片，详情内容可单独滚动；切换模块后回到详情顶部。点击返回、关闭按钮或按 Esc 回到主面板。流程页使用同一原生窗口和同一毛玻璃背景，进入时只调整一次高度，模块之间切换不改变窗口位置或尺寸。返回时一次性恢复主面板高度和原来的滚动位置。

窗口原点使用整点坐标，避免外接屏对半点坐标取整后触发重复定位。返回时先在不可见的主面板上完成布局，再一次性切换内容，快速操作产生的旧切换请求会被丢弃。

流程页返回后继续保留本次面板的锚点，状态栏实时读数宽度改变也不会让面板突然横移；关闭重开或显示器配置变化时重新定位。

图标与连接线仅在有效功率超过 0.05 W 时流动；电池放电会反转方向。未接入、不可用和接近零的读数保持静止，不根据差额猜测功率分配。面板关闭时暂停动画；系统启用“减少动态效果”时保留静态箭头和读数。动画时钟限制在图标和连接线内，不触发遥测采样或窗口尺寸更新。

软件读取当前用户的可访问进程，按应用包归属汇总。CPU 时间转换为纳秒后取差值；能耗使用内核 CPU 能量计数取差，缺失时只按 CPU 活动排序。PID 复用、计数回退与长间隔不沿用旧基线。只读到部分进程能耗时标明覆盖数量。内存是这些进程物理足迹的合计；这些数值都不是整应用完整耗能，也不是活动监视器的“能耗影响”评分。

## 开关与采样

电池净功率和网络上下行外显独立保存于 UserDefaults，默认关闭。偏好设置和右键菜单都能即时切换，不更改其他图标偏好。不可用读数显示破折号；关闭后移除对应外显。

网络面板也提供“状态栏显示实时网速”开关，和偏好设置、右键菜单共用同一持久设置。开启后面板关闭也继续采样，分别展示下载与上传速率。

面板可见或功率外显开启时约每 4 秒读取功耗；面板可见或网络外显开启时约每 2 秒读取流量。应用活动还要求电池详情已展开且用户允许该项。面板关闭且外显关闭时停止快速采样。休眠唤醒清除基线与旧蓝牙报告；异步旧结果不覆盖新状态。

## 验证

纯模型测试覆盖零电量与缺失值、连接状态和地址去重、单侧耳机电量、计数重置、PID 复用、功率方向、SMC 数值编码，以及外显开关的独立性。原生自检使用实际读取的快照，在布局检查前暂停采样，防止硬件状态变化干扰几何断言；可通过 `--preview-details --preview-short` 验证长详情的滚动。

`--smoke-test --preview-readouts` 临时启用两项外显并验证原生状态栏文本，使用进程内参数域，不写入用户持久偏好。

`--smoke-test --preview-power-flow charger|battery|system` 检查指定流程展开后的原生布局，可与 `--preview-short` 组合验证滚动。`--preview-directory` 另行导出三种流程的明暗预览；`--hold-after-test` 可在自检通过后保留窗口供交互检查。

原生自检还会重复切换三个流程并模拟快速打开、返回、再打开，断言三种流程始终使用同一个紧凑窗口、切换模块时窗口尺寸更新次数为零。进入和返回各最多调整一次高度，随后验证主面板高度已恢复且仍可正常调整。测试覆盖正常屏幕与 400 点小视窗。

## 内置屏背光

功率依次检查固定通道 `PDBR`、`PBwo`、`PBLR`，逐项检查编码与 0–150 W 范围；可用的正值优先于仅返回零的通道。亮度百分比、亮度 nit 和驱动电流 mA 来自 `AppleARMBacklight.IODisplayParameters` 的 `brightness`、`BrightnessMilliNits`、`BrightnessMicroAmps`，仅作为显示驱动报告的运行参数，不能直接换算成瓦数。不使用可能停留在零的 `CurrentNits` 属性替代这些字段。

若内屏激活且亮度参数非零，而候选功率返回 0，显示“读数不一致”并保留可读的亮度与电流信息。未激活内屏或亮度设为零时仍允许真实的 0 W；缺少功率通道不推算功耗，也不将其他电源轨误当成屏幕。

本机排查记录：M2 / Mac14,15，`PDBR`、`PBwo` 返回不存在；`PBLR`、`IBLR` 返回零，但内屏亮着，显示驱动报告约 139.7 nit、2.819 mA。因此此时没有可验证的背光瓦数，不能将该零值当作测量成功。正式采样只读固定通道，不做传感器全量枚举。
